# Paper figures (TikZ / pgfplots)

Generated by `scripts/paper_figures.py`. Upload the **contents** of this folder into the
Overleaf project's `figures/` folder.

## One-time setup in root.tex

1. **Compiler:** Menu -> Compiler -> **LuaLaTeX**. pdfLaTeX has a fixed memory limit that
   these figures exceed once they queue up on the same pages.
2. **Preamble:**

```latex
\usepackage[T1]{fontenc}      % required under LuaLaTeX, or the paper loses Times
\usepackage{pgfplots}
\usepgfplotslibrary{groupplots}
\pgfplotsset{compat=1.18}
```

## Including a figure

```latex
\begin{figure*}[t]
  \centering
  \input{figures/equivalence}
  \caption{...}
  \label{fig:equivalence}
\end{figure*}

\begin{figure*}[t]
  \centering
  \def\vostochdata{stochastic_gaussian}          % or stochastic_uniform_ellipse
  \input{figures/stochastic_comparison}
  \caption{...}
  \label{fig:stochastic_gaussian}
\end{figure*}
```

Numbers for the captions, computed from the plotted draw, are in each data folder's
`caption_numbers.txt`.

## Where to edit

| to change | edit |
|---|---|
| colors, mark shape/size/opacity, line styles | `vo_style.tex` (applies to every figure) |
| panel sizes, spacing, titles, axis labels, legend | `equivalence.tex`, `stochastic_comparison.tex` |
| data, lines, limits | re-run the script; don't edit the data folders |

## The data

Each figure reads one table of samples, one row per sample, with a class code per row.
Each point series in the `.tex` keeps the rows with its code.

| folder | files |
|---|---|
| `equivalence/` | `samples.csv` (`x, y, dcpa, tcpa, code_a, code_b, code_c`), `values.tex` |
| `stochastic_gaussian/`, `stochastic_uniform_ellipse/` | `samples.csv` (`tcpa, dcpa, vE, vN, code`), `histograms.csv` (pre-binned marginals), `values.tex` |

When the data changes, re-upload only the data folders, so edits made to the `.tex` files in
Overleaf aren't overwritten.
