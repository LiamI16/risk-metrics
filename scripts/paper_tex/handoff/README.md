# Section 5 figures — three ways to use them

Everything here is generated from one script, so the numbers in the captions, the CSVs and
the figures always come from the same draw. Pick whichever option suits you; they produce
the same figures.

Look at `preview/` first — those PNGs are what the figures look like.

## Option 1 — drop-in PDFs (nothing to set up)

Copy `pdf/*.pdf` into the project's `figures/` folder and include them as usual:

```latex
\begin{figure*}[t]
  \centering
  \includegraphics{figures/equivalence.pdf}     % already the right width; do not rescale
  \caption{...}\label{fig:equivalence}
\end{figure*}
```

They were compiled from the paper itself, so the fonts, sizes and math match exactly.
No preamble changes, no compiler change. Use this if you don't intend to edit the figures.

## Option 2 — TikZ + CSV (editable in Overleaf)

Copy the contents of `figures/` into the project's `figures/` folder, then:

1. **Compiler:** Menu → Compiler → **LuaLaTeX**.
2. **Preamble:**

```latex
\usepackage[T1]{fontenc}      % required under LuaLaTeX, or the paper loses Times
\usepackage{pgfplots}
\usepgfplotslibrary{groupplots}
\pgfplotsset{compat=1.18}
```

3. Include with `\input{figures/equivalence}`; see `figures/README.md`.

Colors and mark styles are in `figures/vo_style.tex`; sizes, titles and legends are in
each figure's `.tex`. The data files are regenerated by the script — don't edit those.

**Why LuaLaTeX:** these figures draw 8,000–10,000 points each. pdfLaTeX has a fixed memory
pool that all three together exceed once they queue up as floats, and it fails with
"TeX capacity exceeded" at the end of the run. LuaLaTeX has no such limit. If you would
rather stay on pdfLaTeX, either use Option 1, or set
`\renewcommand{\vomark}{vosquare}` (square marks are far cheaper) and reduce the sample
counts — ask and we'll regenerate at a lower density.

## Option 3 — just the data

`csv/` holds the three tables on their own, with `csv/DATA.md` describing every column, if
you would rather build the figures your own way.

## Regenerating

`python3 scripts/paper_figures.py` in the code repository rewrites `figures/`, `csv/` and
`preview/`, and repacks this folder. The PDFs in `pdf/` are produced by compiling the
figures inside a copy of the paper, so they match it exactly. Tell us if you want different
sample sizes, colors or panel sizes and we'll re-run both.
